# 📊 Counting Sort en Python

Este proyecto implementa el algoritmo **Counting Sort**, un método de ordenamiento eficiente para listas de números enteros dentro de un rango limitado.

---

## 🧠 ¿Qué es Counting Sort?

**Counting Sort** es un algoritmo de ordenamiento **no comparativo** que funciona contando cuántas veces aparece cada elemento en un arreglo.

En lugar de comparar elementos, utiliza un arreglo auxiliar para almacenar frecuencias.

---

## ⚙️ ¿Cómo funciona?

1. Encontrar el valor máximo del arreglo
2. Crear un arreglo de conteo
3. Contar cuántas veces aparece cada número
4. Reconstruir el arreglo ordenado

---

## 🔢 Ejemplo

### Entrada:

[5, 3, 8, 6, 2, 7, 4, 1, 3, 6, 8, 2, 5, 9, 0, 4, 7, 1, 3, 2]

### Salida:

[0, 1, 1, 2, 2, 2, 3, 3, 3, 4, 4, 5, 5, 6, 6, 7, 7, 8, 8, 9]
